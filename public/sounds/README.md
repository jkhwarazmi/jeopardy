# Sounds

Played on the host screen only, after clicking "Enable Sound". Replace any of these with your own MP3 (keep the filename).

- `buzz.mp3`: someone buzzes in
- `correct.mp3`: answer marked correct
- `wrong.mp3`: answer marked wrong
- `timeup.mp3`: nobody buzzed before the timer ran out
- `reveal.mp3`: a clue is opened
- `final.mp3`: the final round starts
- `winner.mp3`: winner screen

`correct.mp3`, `reveal.mp3` and `final.mp3` are currently short silent placeholders.
