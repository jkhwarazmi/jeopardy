# Jeopardy Sound Effects

All sound files are silent placeholders (~0.25s of silence). Replace with actual MP3s using the same filenames.

## Sound Effects

- **buzz.mp3** — Plays when a player wins the buzz and is selected to answer
- **correct.mp3** — Plays when an answer is marked correct
- **wrong.mp3** — Plays when an answer is marked incorrect
- **timeup.mp3** — Plays when the answer timer or buzz timer expires
- **reveal.mp3** — Plays when a question or answer is revealed on the board
- **final.mp3** — Plays during Final Jeopardy think music (30-second answer window)
- **winner.mp3** — Plays during the winner celebration at the end of the game

**Note:** Sounds play only on the `/host` board screen after clicking "Enable sound". The `/play` and `/admin` interfaces are silent.
